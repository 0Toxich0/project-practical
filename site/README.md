# Оптимальные решения в условиях ограниченных ресурсов

Веб-приложение для решения задачи оптимального распределения ограниченных ресурсов (труд и материалы) между несколькими продуктами методом полного перебора.

**Сайт:** [https://0toxich0.github.io/project-practical/](https://0toxich0.github.io/project-practical/)

## О проекте

Приложение помогает найти оптимальный план производства, максимизирующий прибыль при заданных ограничениях на количество трудовых часов и материалов. Реализует алгоритм полного перебора (brute force), аналогичный решению задачи линейного программирования.

### Зачем это нужно?

- **Для бизнеса:** оптимизация производства при ограниченных ресурсах
- **Для студентов:** наглядная демонстрация работы алгоритмов оптимизации
- **Для программистов:** пример реализации brute force алгоритма на JavaScript

## Возможности

### Основные функции:
- ✅ **Динамическое добавление/удаление продуктов** (до 10 продуктов)
- ✅ **Настройка ресурсов**: общее количество часов и материалов
- ✅ **Автоматическая генерация** случайных значений при добавлении продуктов
- ✅ **Детальный расчёт** с максимальной прибылью

### Результаты расчёта:
- Оптимальное количество каждого продукта
- Максимальная прибыль
- Количество проверенных комбинаций
- Время выполнения расчёта
- Сравнение с максимально возможным количеством

## Как это работает

### Алгоритм:
1. Для каждого продукта вычисляется максимально возможное количество (с учётом ограничений)
2. Рекурсивно перебираются все возможные комбинации количеств продуктов
3. Проверяется соблюдение ограничений по ресурсам
4. Сохраняется комбинация с максимальной прибылью
