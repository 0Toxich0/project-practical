# Оптимальные решения: Производство, Коммивояжёр, Симплекс

Веб-приложение для решения трёх классов оптимизационных задач:

1. **Производственное планирование** – полный перебор с отсечением по ресурсам (максимизация/минимизация прибыли).
2. **Коммивояжёр** – точный перебор всех перестановок для поиска оптимального порядка операций (3–8 операций) с визуализацией графа.
3. **Симплекс-методы** – классический симплекс (max, ≤) и двойственный симплекс (min, ≥) для задач линейного программирования.

## О проекте

Приложение помогает:

- Найти оптимальный план выпуска продуктов при ограничениях на трудовые ресурсы и материалы.
- Определить кратчайший маршрут коммивояжёра (порядок выполнения операций) с визуализацией на графе.
- Решить задачу линейного программирования симплекс-методом (максимизация, ограничения ≤) или двойственным симплекс-методом (минимизация, ограничения ≥).

Все алгоритмы реализованы **точно** (полный перебор для TSP, симплекс-таблицы для ЛП) и сопровождаются подробной статистикой и визуализацией.

## Возможности

### 1. Производство

- **Динамическое управление продуктами** – добавление/удаление до 10 продуктов.
- **Ресурсы** – общее количество часов и материалов (настраивается).
- **Два режима оптимизации**:
  - Максимизация прибыли
  - Минимизация прибыли
- **Алгоритм** – рекурсивный перебор всех допустимых комбинаций с отсечением по ресурсам.
- **Результаты**:
  - Оптимальное количество каждого продукта
  - Значение прибыли
  - Использование ресурсов (в абсолютных величинах и процентах)
  - Количество проверенных комбинаций и ускорение по сравнению с полным перебором
- **Визуализация**:
  - Столбчатая диаграмма использования ресурсов
  - Круговая диаграмма эффективности продуктов
- **Экспорт** – история расчётов сохраняется в `localStorage`, можно очистить.
- **Детальная таблица** с трудозатратами, расходом материала, прибылью и эффективностью.

### 2. Коммивояжёр

- **Количество операций** – от 3 до 8.
- **Полный перебор всех перестановок** – гарантированно находит оптимальный маршрут.
- **Матрица времени перехода** – симметричная, редактируемая вручную или заполняемая случайными числами.
- **Лимит времени** – позволяет проверить, укладывается ли оптимальный маршрут в заданное ограничение.
- **Результаты**:
  - Оптимальная последовательность операций (с замыканием в цикл)
  - Общее время маршрута
  - Количество просмотренных перестановок
  - Время выполнения расчёта
- **Визуализация графа**:
  - Отображение всех связей с подписями расстояний
  - Выделение оптимального маршрута красными линиями
  - Нумерация операций
- **Информация о соблюдении лимита** – цветовой индикатор и текстовое сообщение.

### 3. Симплекс-методы

#### Симплекс

- **Условия:** `Ax ≤ b`, `x ≥ 0`, `b ≥ 0`.
- **Алгоритм:** классический табличный симплекс с добавлением slack-переменных.
- **Вывод:** оптимальное решение `x*`, максимальное значение целевой функции, пошаговые итерации (ведущие элементы).
- **Обработка ошибок:** проверка неотрицательности `b`, обнаружение неограниченности.

#### Двойственный симплекс

- **Условия:** `Ax ≥ b`, `x ≥ 0` (правые части `b` могут быть любыми).
- **Алгоритм:** преобразование к виду `-Ax ≤ -b` и применение двойственного симплекс-метода.
- **Вывод:** оптимальное решение, минимальное значение ЦФ, итерации.
- **Обработка ошибок:** определение несовместности.

#### Общее для симплексов

- **Настройка размерности** – количество переменных (2–5) и ограничений (1–5).
- **Динамическое формирование полей ввода** – кнопка «Сформировать».
- **Примеры по умолчанию** – заполнены тестовыми данными для демонстрации.
- **Читаемый вывод** – решение округлено до 4 знаков, шаги представлены в текстовом виде.

## Как это работает

### Производство

Для каждого продукта вычисляется максимально возможное количество по каждому ресурсу (`maxCount[i] = min(часы / труд, материал / расход)`).  
Рекурсивная функция перебирает все комбинации `(cnt1, cnt2, ..., cntN)`, где `0 ≤ cnt_i ≤ maxCount[i]`.  
Если на каком-то шаге ресурсы превышены, ветка отсекается.  
В конце выбирается комбинация с максимальной (или минимальной) прибылью.

**Сложность:** `O(∏ (maxCount[i]+1))`, но отсечение сокращает реальное число проверок.

### Коммивояжёр

Генерируются все перестановки городов (операций). Для каждой перестановки вычисляется суммарное время прохода по всем городам и возврата в первый.  
Выбирается перестановка с минимальным временем.  
Число перестановок для `n` операций равно `(n-1)!/2` (с учётом симметрии направления).  
При `n=8` это 2520 перестановок – расчёт выполняется мгновенно.

### Симплекс-метод

1. **Стандартный симплекс:**

   - Добавляются slack-переменные, чтобы превратить неравенства в равенства.
   - Строится симплекс-таблица (m строк + 1 строка цели).
   - Пока в строке цели есть отрицательные коэффициенты, выбирается ведущий столбец (минимальный отрицательный).
   - Ведущая строка – по минимальному отношению `b / a_ij` (только для положительных `a_ij`).
   - Выполняется пересчёт таблицы методом Гаусса–Жордана.
   - После достижения неотрицательности всех коэффициентов целевой строки решение извлекается из столбца правых частей для базисных переменных.

2. **Двойственный симплекс:**
   - Исходные ограничения `Ax ≥ b` умножаются на `-1`, превращаясь в `-Ax ≤ -b`.
   - Добавляются slack-переменные, правые части могут быть отрицательными.
   - Критерий выбора ведущей строки – самая отрицательная правая часть.
   - Ведущий столбец – по минимальному отношению коэффициентов целевой строки к отрицательным элементам ведущей строки.
   - Пересчёт таблицы аналогичен обычному симплексу.
   - Процесс продолжается, пока все правые части не станут неотрицательными.

## Пример использования

### Производство

1. Введите общее количество часов и материалов.
2. Добавьте продукты (название, труд, материал, прибыль).
3. Выберите режим (максимизация или минимизация).
4. Нажмите «Найти оптимальное решение».
5. Проанализируйте таблицу, графики и историю.

### Коммивояжёр

1. Перейдите на вкладку «Коммивояжёр».
2. Установите количество операций (3–8).
3. Отредактируйте матрицу времени перехода (или нажмите «Случайные данные»).
4. При желании задайте лимит времени.
5. Нажмите «Найти оптимальный маршрут».
6. Посмотрите оптимальную последовательность, время и визуализацию на графе.

### Симплекс

1. Перейдите на вкладку «Симплекс-методы».
2. Выберите подвкладку «Симплекс (≤, max)» или «Двойственный (≥, min)».
3. Укажите количество переменных и ограничений, нажмите «Сформировать».
4. Заполните коэффициенты целевой функции, матрицу `A` и правые части.
5. Нажмите «Решить симплексом» (или «Двойственный симплекс»).
6. Ознакомьтесь с оптимальным решением и пошаговыми итерациями.

## Технические детали

- **Язык:** JavaScript (ES6)
- **Фреймворки / библиотеки:**
  - Bootstrap 5 – адаптивный интерфейс
  - Chart.js – графики
  - SheetJS – экспорт в XLSX (опционально)
- **Хранение истории:** `localStorage`
- **Алгоритмы:**
  - Рекурсивный перебор с отсечением (производство)
  - Рекурсивный перебор перестановок (коммивояжёр)
  - Табличный симплекс и двойственный симплекс (ЛП)
- **Графика:** Canvas для рисования графа коммивояжёра
- **Совместимость:** все современные браузеры, адаптивная вёрстка (мобильные устройства)
