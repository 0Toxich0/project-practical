# Оптимальные решения в условиях ограниченных ресурсов

Веб-приложение и консольная программа для решения задачи оптимального распределения ограниченных ресурсов (труд и материалы) между несколькими продуктами методом полного перебора с отсечением по ресурсам.

**Сайт:** [https://0toxich0.github.io/project-practical/](https://0toxich0.github.io/project-practical/)

**Отчёт:** [Отчёт](Отчёт.pdf)

**Презентация:** [Презентация](Презентация.pdf)

## О проекте

Приложение помогает найти оптимальный план производства, максимизирующий или минимизирующий прибыль при заданных ограничениях на количество трудовых часов и материалов. Реализует алгоритм полного перебора с отсечением неперспективных вариантов по ресурсам.

### Зачем это нужно?

- **Для бизнеса:** оптимизация производства при ограниченных ресурсах
- **Для студентов:** наглядная демонстрация работы алгоритмов оптимизации
- **Для программистов:** пример реализации алгоритма перебора на JavaScript и C++

## Возможности

### Основные функции:

- **Динамическое добавление/удаление продуктов** (до 10 продуктов)
- **Настройка ресурсов**: общее количество часов и материалов
- **Ручной ввод данных с валидацией**
- **Два режима расчёта**:
  - **Максимизация прибыли** - поиск наиболее прибыльного плана
  - **Минимизация прибыли** - поиск наименее прибыльного допустимого плана
- **Оптимизированный перебор** - отсечение по ресурсам
- **Детальный расчёт** с оптимальным значением прибыли

### Алгоритм:

- **Отсечение по ресурсам** – если ресурсы превышены, ветка дальше не рассматривается
- **Полный перебор допустимых комбинаций** – гарантированно находим оптимальное решение
- **Статистика расчёта** – количество проверенных комбинаций и ускорение

### Визуализация:

- **График использования ресурсов** (столбчатая диаграмма)
- **График эффективности продуктов** (круговая диаграмма)
- **Прогресс-бары** использования ресурсов
- **Цветовая индикация** режимов (зелёный для максимума, красный для минимума)

### Экспорт данных:

- **XLSX** - для анализа в Excel
- **JSON** - для программной обработки
- **TXT** - для текстового отчёта

### Дополнительные возможности:

- **История расчётов** с сохранением в localStorage
- **Индикатор сложности** - показывает теоретическое число комбинаций
- **Статистика ускорения** - сравнение с полным перебором

## Результаты расчёта:

- Оптимальное количество каждого продукта
- Максимальная или минимальная прибыль (в зависимости от режима)
- Количество проверенных комбинаций
- Время выполнения расчёта
- Процент использования ресурсов
- Эффективность каждого продукта

## Как это работает

### Алгоритм:

1. Для каждого продукта вычисляется максимально возможное количество
2. Рекурсивно перебираются все возможные комбинации
3. **Отсечение по ресурсам**: если ресурсы превышены, ветка дальше не рассматривается
4. В зависимости от выбранного режима сохраняется комбинация с:
   - **Максимальной прибылью** (режим максимизации)
   - **Минимальной прибылью** (режим минимизации)

### Пример использования:

1. Введите количество продуктов и их характеристики
2. Укажите доступные ресурсы (часы и материалы)
3. Выберите режим оптимизации
4. Нажмите "Найти оптимальное решение"
5. Изучите результаты, графики и экспортируйте данные при необходимости

- LocalStorage для истории
- Рекурсивный перебор с отсечениями

### Консольная версия (C++):

- Стандартная библиотека C++

## Производительность

Благодаря отсечению по ресурсам, алгоритм проверяет только допустимые комбинации:

- Ускорение зависит от структуры задачи (в примере: 5.24x)
- Отсечение по ресурсам сокращает количество проверяемых комбинаций
- Гарантированно находится оптимальное решение
