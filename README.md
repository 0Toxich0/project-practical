# Оптимальные решения в условиях ограниченных ресурсов

Веб-приложение и консольная программа для решения задачи оптимального распределения ограниченных ресурсов (труд и материалы) между несколькими продуктами методом полного перебора с улучшенным алгоритмом Branch and Bound.

**Сайт:** [https://0toxich0.github.io/project-practical/](https://0toxich0.github.io/project-practical/)

**Отчёт:** [Отчёт](Отчёт.pdf)

## О проекте

Приложение помогает найти оптимальный план производства, максимизирующий или минимизирующий прибыль при заданных ограничениях на количество трудовых часов и материалов. Реализует алгоритм полного перебора (brute force) с оптимизациями Branch and Bound.

### Зачем это нужно?

- **Для бизнеса:** оптимизация производства при ограниченных ресурсах
- **Для студентов:** наглядная демонстрация работы алгоритмов оптимизации
- **Для программистов:** пример реализации brute force алгоритма на JavaScript и C++

## Возможности

### Основные функции:
- **Динамическое добавление/удаление продуктов** (до 10 продуктов)
- **Настройка ресурсов**: общее количество часов и материалов
- **Автоматическая генерация** случайных значений при добавлении продуктов
- **Два режима расчёта**:
  - **Максимизация прибыли** - поиск наиболее прибыльного плана
  - **Минимизация прибыли** - поиск наименее прибыльного допустимого плана
- **Branch and Bound оптимизация** - ускорение расчётов в десятки раз
- **Детальный расчёт** с оптимальным значением прибыли

### Улучшенный алгоритм:
- **Раннее отсечение** по ресурсам
- **Верхняя граница прибыли** для отсечения неперспективных веток
- **Сортировка по эффективности** для максимизации
- **Статистика отсечённых веток** и ускорения

### Визуализация:
- **График использования ресурсов** (столбчатая диаграмма)
- **График эффективности продуктов** (круговая диаграмма)
- **Прогресс-бары** использования ресурсов
- **Цветовая индикация** режимов (зелёный для максимума, красный для минимума)

### Экспорт данных:
- **CSV** - для анализа в Excel/Google Sheets
- **JSON** - для программной обработки
- **TXT** - для текстового отчёта

### Дополнительные возможности:
- **История расчётов** с сохранением в localStorage
- **Загрузка примера** задачи для быстрого старта
- **Индикатор сложности** - показывает теоретическое число комбинаций
- **Статистика ускорения** - сравнение с полным перебором

## Результаты расчёта:
- Оптимальное количество каждого продукта
- Максимальная или минимальная прибыль (в зависимости от режима)
- Количество проверенных комбинаций
- Время выполнения расчёта
- Процент использования ресурсов
- Эффективность каждого продукта

## Как это работает

### Алгоритм Branch and Bound:
1. Для каждого продукта вычисляется максимально возможное количество
2. Продукты сортируются по эффективности (для максимизации)
3. Рекурсивно перебираются все возможные комбинации
4. **Отсечение по ресурсам**: если ресурсы превышены, ветка дальше не рассматривается
5. **Отсечение по прибыли**: если максимально возможная прибыль оставшихся продуктов меньше текущего оптимума, ветка отсекается
6. В зависимости от выбранного режима сохраняется комбинация с:
   - **Максимальной прибылью** (режим максимизации)
   - **Минимальной прибылью** (режим минимизации)

### Пример использования:
1. Введите количество продуктов и их характеристики
2. Укажите доступные ресурсы (часы и материалы)
3. Выберите режим оптимизации
4. Нажмите "Найти оптимальное решение"
5. Изучите результаты, графики и экспортируйте данные при необходимости

## Производительность

Благодаря Branch and Bound оптимизации, алгоритм работает значительно быстрее полного перебора:
- **10 продуктов** с maxCount=10: 285 млрд комбинаций → проверяется только несколько тысяч
- **Ускорение** может достигать 10 000x и более
- **Отсечение по ресурсам** отбрасывает до 99% неперспективных веток
